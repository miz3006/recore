# Expo HAS CHANGED

Read the exact versioned docs before writing any code — Expo, Reanimated and
StoreKit all move faster than any model's training data.

The project is on **SDK 54** today (https://docs.expo.dev/versions/v54.0.0/).
`PLAN.md` 0.3 moves it to the current stable release; until that task is ticked,
do not use APIs from a later SDK.

Recore builds as a **development build**, not Expo Go — `npx expo run:ios`, see
`README.md`. Expo Go was dropped in 0.1 and nothing may reintroduce a dependency
on it (CLAUDE.md §19.1).
